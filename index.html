Create and Link a CSS File

Follow these steps in order:

  1. Add a new CSS style page.
  2. Rename new.css to style.css.
  3. In style.css, add a background-color declaration inside the body { } rule-set.
  4. In index.html, place the stylesheet <link> inside the <head>.
  5. Click Check My Files.
